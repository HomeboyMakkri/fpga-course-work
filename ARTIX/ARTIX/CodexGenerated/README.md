# Черновой перенос блока из Smart Artix

Используйте **ARTIX_Codex_Verified.PrjPcb** и **Clock_Flash_Verified.SchDoc**.
Это QSPI flash и генератор 50 MHz из страницы 6 PDF: 8 компонентов, 24 вывода.
23 подключённых вывода проверены по physical-netlist Altium; X6.1 оставлен NC.
Полный перенос FPGA, питания, Ethernet и входов/выходов ещё не завершён.
Остаются 4 ошибки ERC из-за сетей, которые должны продолжаться к отсутствующей FPGA,
и предупреждения о footprint/сетке. Черновые символы не готовы к разводке.

Clock_Flash.SchDoc / ARTIX_Codex.PrjPcb — ранние диагностические версии.
Интеграция, исходники, тесты и восстановление дополнений: ../../../tools/altium/README.md.
