# Повторное редактирование библиотек Altium через Codex

Навык хранится в `.agents/skills/altium-library/SKILL.md` этого репозитория. MCP `altium_local` запускается из `tools/altium`; его настройка хранится в `.codex/config.toml`. Исходники и навык обновляются обычным `git pull`.

Проверенные отчёты: `output/altium/library-workflow-mcp-test.json` и остальные файлы в `output/altium`.

Для нового чата откройте один экземпляр Altium, нужную SchLib и нужный компонент. Пример:

> Используй $altium-library и altium_local. В библиотеке `<полный путь к SchLib>`, компонент `<LibReference>`, задай всем выводам длину 5 мм и шрифт имени/номера GOST Common 10 pt. Сохрани резервную копию и проверь результат после сохранения.

Для другого изменения опишите желаемые части, порядок пинов и оформление. Codex должен составить полный manifest по физическим номерам, затем вызвать `altium_repartition_library_component`. Таблица FPGA A–J находится в `manifests/xc7a50t-parts.json`.

Новые инструменты:

| Инструмент | Назначение |
|---|---|
| `altium_inspect_library_component` | Чтение всех выводов и их шрифтов из редактора |
| `altium_format_library_pins` | Длина в мм, Name/Designator font и размер в pt |
| `altium_repartition_library_component` | Части, порядок и координаты по полному manifest |

Команды изменения создают две копии: прежний файл на диске и сохранённое текущее состояние редактора. После изменения библиотека сохраняется, повторно читается Altium и сравнивается с исходным состоянием. Отчёты и копии остаются в `runtime/library-reports` и `runtime/backups` постоянной установки.

Если новые имена инструментов ещё не появились, переподключите MCP либо перезапустите Codex. В текущем подключении старый список инструментов может оставаться прежним. CLI-команды используют тот же код; инструкция внутри навыка.

Штатный API всё ещё может выдавать ошибки или зависать. После тайм-аута сначала читаются журнал и фактическое состояние; изменения вслепую не повторяются. Для новой версии Altium или ещё не поддержанной операции сначала используется отдельная копия библиотеки.
