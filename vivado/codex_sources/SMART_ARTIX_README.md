# Smart Artix: контакты PPS

Актуальная прошивка управляется по Ethernet, после reset все каналы OFF.
Инструкция и протокол: [vivado/README.md](../README.md).

| Выход | FPGA | Контакт J5 |
|---|---|---:|
| PPS1 | B1 | 7 |
| PPS2 | C2 | 9 |
| PPS3 | E1 | 11 |
| GND анализатора | GND | 5 или 6 |

Частота каждого выхода независимо OFF/1/10/100 PPS. Активный уровень высокий,
один такт внутренней опоры 10 МГц (номинально 100 нс). KEY3 T20 — reset.
Опора 10 МГц получена из генератора платы 50 МГц Y18 через MMCM.

Нумерация по схеме, не по фотографии; сверить pin1 и ревизию. J5 pin1/2=5 В,
pin3/4=3,3 В. Вход анализатора должен допускать 3,3 В. Нагрузка 50 Ом не
предусмотрена. Новая Ethernet-прошивка на плате ещё не проверена.
Прежний `bitstream/smart_artix_pps.bit` автоматически формировал 1/10/100 PPS;
его измерения нельзя считать проверкой текущего RTL.
