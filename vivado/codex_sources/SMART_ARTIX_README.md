# Smart Artix: первая проверка PPS

Тестовая оболочка использует 50 МГц на Y18, MMCM формирует 10 МГц. После выхода из reset автоматически запускаются каналы 1, 10, 100 PPS; импульс активный высокий, длительностью 100 нс номинально. KEY3 (T20) — сброс. Это стендовый режим; Ethernet и изменение частоты командой ещё не подключены.

По схеме Smart Artix v1.3, лист 9, разъём J5, BANK35 (3,3 В):

| Сигнал | FPGA | Номер контакта J5 |
|---|---|---:|
| PPS1, 1 Гц | B1 | 7 |
| PPS2, 10 Гц | C2 | 9 |
| PPS3, 100 Гц | E1 | 11 |
| Земля анализатора | GND | 5 или 6 |

Нумерация дана по схеме разъёма, не по расположению контактов на фотографии. Сначала установить ориентацию pin 1 по маркировке платы и сверить ревизию/питание: на том же J5 контакты 1–2 = 5 В, 3–4 = 3,3 В. Убедиться, что вход анализатора допускает 3,3 В; не использовать выходы как источник для 50-омной нагрузки.

Сброс и MMCM LOCKED должны стабилизироваться до начала формирования PPS. Значения частот определяются точностью физического 50-МГц генератора. Данный файл не подтверждает проверку на плате.
